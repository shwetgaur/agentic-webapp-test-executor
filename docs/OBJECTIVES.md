# Project Objectives (FINAL)

## Problem Statement (Dassault DS 1)
Uses basic text steps as input to automatically replay user actions on a web app.
Follow steps, execute the flow, and verify whether the app behaves as expected.
Domain: Quality Engineering.

## Objectives
1. Interpret basic text-based test steps into structured executable actions.
2. Execute those actions automatically on a target web application using Playwright.
3. Verify application behavior using assertions on UI state.
4. Generate structured documentation of each test run (pass/fail + screenshots/logs).
5. Notify the responsible team on failure (scrum-master style alerts + ticket id).
6. Reduce brittleness via AI-assisted step understanding / basic locator recovery.
7. Evaluate on sample web apps and produce college + Dassault documentation.

## Demo Success Criteria
- Run plain-text steps without hand-writing Playwright scripts.
- Show >=3 passing flows and 1 intentional failure with evidence.
- Open a pass/fail report for the run.
- Show failure notification routed to the mapped owning team.
